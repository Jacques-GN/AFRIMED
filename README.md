# AFRIMED - Prototype

Application web de consultation médicale assistée par IA, conçue pour les établissements de santé en Afrique.

## Stack
- React + Vite
- Tailwind CSS
- Supabase
- Google Gemini API

## Installation
npm install
npm run dev

## Variables d'environnement
Copiez le fichier .env.example en .env et remplissez-le avec vos clés réelles.
